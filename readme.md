# parolee

Fork of [SogoCZE/Jails](https://github.com/SogoCZE/Jails). The reason this fork exists is my need to store this somewhere, but I do not want to PR vibecoded pieces of code I never checked. This repo is result of LLM getting hog-wild on my "Hey, i want this thing and that thing, also i want dogs to dance and pink balloons everywhere, now go make it happen".

## Features

- **Semantic syntax highlighting** — full LSP semantic tokens provider with delta updates.
- **Autocomplete** — symbols, types, procedures, variables, keywords. Even for generated types.
